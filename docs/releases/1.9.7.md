# AdBlocker 1.9.7

**Status: draft pre-release candidate. Not approved for public distribution.**

- Version name: 1.9.7
- Version code: 19
- Application ID: `com.example.adblocker`
- Build: owner-signed APK produced by the manual GitHub Actions workflow.
- Integrity: SHA-256 checksum is attached as `SHA256SUMS`.

## What's changed

- More reliable Gradle dependency resolution in CI using the Gradle setup action's basic dependency cache.
- Bounded retries for transient dependency-download HTTP 429/502/503/504 failures only.
- Compilation, lint, and unit-test failures are not retried away.
- Offline self-tests cover successful builds, transient and persistent download failures, compilation failures, and mixed test failures.
- Debug and signed APK identity, version metadata, ZIP integrity, signature, and checksum are verified by CI.

## Runtime scope

This release candidate does not introduce DNS/VPN runtime behavior changes compared with the previous app code. AdBlocker remains a DNS-only Android VPN. It does not intercept all traffic or universally block app-originated encrypted DNS (DoH/DoT).

## Release gate

**Do not publish this draft to the public Releases page or distribute the APK yet.**

Physical-device validation in issue #64 remains required, including VPN lifecycle, DNS UDP/TCP over IPv4/IPv6, DoH failure behavior, network handoff, background scheduling, settings migration, privacy, and signed in-place upgrade. Android CI and emulator smoke do not replace this testing.

After the owner records the required physical-device evidence and approves the candidate, review the draft release and publish it manually from GitHub.
