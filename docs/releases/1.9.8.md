# AdBlocker 1.9.8 (release candidate)

**Status: draft pre-release candidate. Physical-device verification pending.**

- Version name: 1.9.8
- Version code: 20
- Application ID: `com.example.adblocker`
- Release signing: reuse the existing AdBlocker keystore. Do **not** generate a new key.

## Fixed

- The Pause DNS blocking dialog now shows the warning **and** three full-width duration options (5, 15, and 30 minutes). The previous `AlertDialog.setMessage()` + `setItems()` combination caused the options to be hidden on a physical Android device.
- Cancel dismisses without pausing. Selecting a duration pauses blocking only while the VPN is running. Resume remains available from the main screen.
- The choice layout scrolls on smaller screens and uses localized Android string resources (English/Arabic).

## Verification

- CI must pass `lintDebug`, `testDebugUnitTest`, APK metadata verification, and `assembleDebug`.
- Android 16 emulator smoke must pass install/launch/rotation/relaunch.
- **Required manual verification:** on a real phone, open Pause, see the three durations, choose 5 minutes, confirm the status/countdown and re-blocking at expiry; then confirm 15/30-minute selections, Cancel, and manual Resume. Repeat with Arabic and large display text.
- Check in-place upgrade from the signed 1.9.7 candidate (versionCode 19) to a 1.9.8 build signed with the same key, preserving settings.

## Scope and release gate

No DNS packet parsing or tunnel transport behavior is changed. The app is a DNS-only VPN; it does not intercept every encrypted DNS client or route arbitrary traffic. Issue #64 remains open until broader physical-device tests pass. Do not publish a draft publicly or represent device validation as complete.
